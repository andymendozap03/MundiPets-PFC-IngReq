Recuperar contraseña

Sigue estos pasos para verificar tu identidad y establecer una nueva contraseña.

1. Ingresa tu correo electrónico

Te enviaremos un código de verificación de 6 dígitos a tu correo registrado.

2. Verifica el código

Hemos simulado el envío de un correo con tu código. Como este MVP no tiene servidor de correo, el código se muestra a continuación únicamente con fines de demostración.

3. Crea una nueva contraseña

La contraseña debe cumplir con la política de seguridad de MundiPets.
